### Project Documentation
For Software:Keep the existing game logic, structure, mechanics, and features. Only update the visual assets (sprites) to use the new pixel-art shapes I've provided. Do not replace the entire project - just swap the visuals and adjust the drawing/rendering code accordingly.

1. UPDATE SPRITES

Replace the current dino, cactus and flying bird graphics with the exact shapes from the images I provided.

Dino: Use the first image (the upright pixel-art dino). Implement running, jumping, falling and death animations using this shape. Keep the same style (monochrome, pixelated).

Cactus: Use the second image (the horizontal/angled cactus). Implement proper ground collision, movement, and animations (walking, emerging, hidden, tracking, etc.).

Bird: Use the third image (the flying bird). Implement wing flapping, altitude changes, dive attack, targeting, and fireball attack (if applicable).

Maintain the same minimal, monochrome, pixel-art style as the original Chrome Dino game.

2. UPDATE ANIMATION LOGIC

Dino: Use the new dino shape for all animations (run, jump, fall, die).

Cactus: Use the new cactus shape for all movement types (normal, tracking, emerging, hidden, double, etc.).

Bird: Use the new bird shape for flight, dive, and fireball attack.

Keep the existing physics, collision detection, timing, and game loop logic. Just replace the graphics with these new sprites.

3. ADJUST COLLISION BOXES

Update the hitboxes to match the new shapes (slightly smaller than the visible sprite for fairness).

Ensure the cactus, bird and fireballs actually interact with the dino (collision, damage, death).

Make sure the new bird shape still targets the dino correctly and adjusts its position/altitude.

4. VISUAL STYLE

Keep the game monochrome (dark gray/black on white background) like the Chrome Dino game.

Use crisp pixel-art rendering. No smooth graphics, no emojis, no HTML boxes.

The only exception is the fireballs, which can remain orange pixel-art (if already implemented).

5. TEST

After updating, verify that the following work correctly with the new visuals:

1. Dino running, jumping, falling, dying

2. Cactus movement and collision

3. Hidden cactus emergence

4. Tracking cactus under jump

5. Bird movement and targeting

6. Bird dive attack

7. Bird fireball attack and collision

8. Void / falling animation

9. Black-screen surprise event

10. Special game over message (if triggered)
